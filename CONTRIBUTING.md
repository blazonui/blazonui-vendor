# Mitmachen bei BlazonuiVendor

Danke für dein Interesse! Kurz vorweg: Dieses Repository ist **quelloffen einsehbar, aber kein
klassisches Open-Source-Projekt** — Details dazu in der [LICENSE](LICENSE).

## Bugs melden & Vorschläge

Bitte **nicht** als GitHub-Issue, sondern über unseren Discord:

- `/report` für Bugs
- `/suggest` für Feature-Wünsche

→ [Discord beitreten](https://blazonui.de/join)

## Code-Beiträge (Pull Requests)

Der Quellcode steht unter einer eingeschränkten Lizenz (keine Forks/Weiterverbreitung ohne
Zustimmung). Wir nehmen deshalb aktuell **keine unaufgeforderten Pull Requests** an. Bei
Interesse an einer Zusammenarbeit einfach vorab kurz an **support@blazonui.de** schreiben —
dann stimmen wir das gemeinsam ab.

## Warum überhaupt öffentlich?

Volle Transparenz: Jeder kann nachvollziehen, was das Addon tatsächlich tut, bevor er es
installiert — kein "Blackbox"-Vertrauen nötig.
